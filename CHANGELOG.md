# Изменения

## 0.2.0 — 24 октября 2026

- **Свои окна выбора файлов для других программ.** Бэкенд портала `xdg-desktop-portal-shelf`
  открывает Shelf в режиме выбора: открыть один или несколько файлов, выбрать папку, сохранить
  (с подтверждением замены), сохранить несколько файлов в папку; фильтры типов и параметры
  от приложения. Работает в Firefox, Chromium, Electron, Telegram, Flatpak, Qt- и GTK-программах.
- Включается переключателем «Выбор файлов в окнах Shelf» в настройках и в первой настройке:
  прописывает бэкенд в `~/.config/xdg-desktop-portal`, а GTK-программам и Firefox — переменные
  в `~/.config/hypr/shelf.conf` (с копиями `.bak-shelf`). Выключение возвращает всё как было.
- В окне выбора: Enter / двойной щелчок по файлу — выбрать, Ctrl+Enter — кнопка действия,
  Esc — отмена

## 0.1.2 — 24 октября 2026

- **Пакеты для Debian 13 и Ubuntu 25.04+** (`.deb`) и **для Arch** (`shelf-fm`, PKGBUILD в
  `packaging/arch/`; в AUR — как только там снова откроют регистрацию)
- Подсветка активной вкладки больше не перескакивает при перетаскивании вкладок (#1)
- `shelf --version` работает и без графической сессии (по SSH, в скриптах)

## 0.1.1 — 24 октября 2026

- **Пакет для Nix:** `flake.nix` — `nix run github:Stasyao37/shelf` запускает Shelf без установки,
  есть пакет для профиля и оверлей для NixOS
- **Один RPM для Fedora 43 и новее:** QML собирается в байт-код без закрытого API Qt, поэтому
  пакет больше не привязан к точной версии Qt
- **Проводник по умолчанию** — переключатель в первой настройке и кнопка в настройках
- **Иконки:** все детали лежат на стекле светлым слоем, без тёмных контуров; ключ, печать и
  страницы книги стоят перед основой и не просвечивают
- README: о Shelf как о файловом менеджере для Hyprland и о глассморфизме

## 0.1.0 — 24 октября 2026

Первый выпуск.

### Файлы и папки
- Сетка и список, история назад/вперёд, хлебные крошки с вводом пути, скрытые файлы, поиск вглубь
- Копирование, перемещение и вставка с прогрессом и отменой, переименование на месте, новая папка,
  свойства; буфер обмена совместим с GNOME-приложениями
- «Открыть с помощью» по `mimeapps.list`, с выбором приложения по умолчанию
- Корзина: удаление, восстановление на прежнее место, удаление навсегда, очистка
- Перетаскивание внутри окна, между вкладками и в другие программы; подержать над папкой — откроется

### Вкладки
- Своя папка, история и поиск у каждой; перетаскиваются, средняя кнопка открывает в новой вкладке
- После выключения компьютера или сбоя Shelf предлагает вернуть вкладки

### Вид
- Стеклянный набор иконок, нарисованный с нуля; мягкий оттенок из палитры по типу файла
- Миниатюры из общего кэша, недостающие делает tumbler
- Цвета от Quickshell, matugen или встроенной светлой и тёмной темы; стекло по размытию Hyprland
- Анимации переходов, окон и появления файлов (выключаются в настройках)

### Для любого пользователя Hyprland
- Первая настройка: проверка окружения с подсказками установки, подключение к matugen
- Настройки: источник цветов, стекло, оттенок иконок, анимации, терминал
- Терминал выбирается сам (`$TERMINAL`, `xdg-terminal-exec`, kitty, foot, alacritty…)
- Значки интерфейса вшиты в программу — Nerd Font не нужен
